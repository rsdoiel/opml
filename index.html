opml

A package to manipulate OPML files in Go. It is based on the spec as described at http://dev.opml.org/spec2.html. The opml package imports only the standard library. It reads and writes OPML (UTF-8, ISO-8859-1, US-ASCII and windows-1252 input), walks an outline, and can list the pages of a table of contents with Flatten() and Includes(). The cmark package converts an outline to a CommonMark list and back.

It includes command line programs that demonstrate it (each has a manual page; the user manual lists them):

  • opmlsort: sorts an OPML outline by text attribute values
  • opmlcat: concatenates one or more OPML outlines
  • opml2json: converts an OPML file into a JSON document
  • opml2urls: lists the feed URLs of an OPML file, or the pages of a table of contents, or writes newsboat’s url file
  • urls2opml: converts a list of urls into OPML XML
  • opml2cmark: writes an OPML outline as a CommonMark list, to edit in a text editor
  • cmark2opml: reads that Markdown list back into OPML

See INSTALL to install them and CHANGES for what changed in each release.
